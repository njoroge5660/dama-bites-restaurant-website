# DAMA BITES website starter

This is the first static website version for DAMA BITES. It uses HTML, CSS and JavaScript only.

## Files
- `index.html` — page content and sections
- `styles.css` — colours, layout and responsive design
- `script.js` — menu rendering, category filters and WhatsApp order links

## Run it locally with VS Code and XAMPP
1. Extract this ZIP file.
2. Copy the `dama_bites_website` folder into `C:\xampp\htdocs\`.
3. Open that folder in VS Code.
4. Start **Apache** in the XAMPP Control Panel.
5. In your browser, visit `http://localhost/dama_bites_website/`.

You do not need MySQL for this first version.
